# Watt Conta

App web para estimar o consumo de energia da casa, desenvolvido para o projeto de extensão
"Comunidade Sustentável" do curso de Análise e Desenvolvimento de Sistemas (Cruzeiro do Sul Virtual).

- Lista de aparelhos com potência típica, tempo de uso e dias por mês.
- Consumo em kWh e custo estimado por aparelho; ranking de quem mais gasta.
- Dicas de economia com o valor economizado calculado.
- Comparação com a conta de luz real e cálculo da tarifa (valor ÷ kWh).
- Dados salvos apenas no aparelho do usuário, sem login e sem servidor; funciona offline (PWA).
